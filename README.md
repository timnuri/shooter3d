# Последний рубеж

3D-шутер от третьего лица для Android: оборона от волн роботов.
Движок — Godot 4.7.

## Где взять игру

- **Проверить в браузере (на телефоне):** https://timnuri.github.io/shooter3d/
- **Приложение (APK):** раздел **Releases** справа → `shooter3d.apk`.

Обе версии собираются автоматически после каждого изменения (вкладка **Actions**, 5–15 минут).

## Управление на телефоне

- Левая часть экрана — джойстик (появляется там, где коснулись).
- Правая часть экрана — обзор пальцем.
- «Огонь» — зажать; пока держите, можно вести пальцем и целиться.
- «Прицел», «Прыжок», «Патроны» (перезарядка), «Оружие» (смена), «II» (пауза).
- Чувствительность и графика — в «Настройках».

На ПК: WASD, мышь, ЛКМ — огонь, ПКМ — прицел, R — перезарядка, Q/1/2/3 — оружие, Esc — пауза.

## Как устроен проект

- `game/` — наш код и изменённые файлы игры.
- `tools/prepare.sh` — скачивает [Godot TPS Demo](https://github.com/godotengine/tps-demo)
  (уровень, модели, анимации, звуки) и накладывает поверх папку `game/`.
- `.github/workflows/build.yml` — автосборка версии для браузера и APK.
- `android/test-release.keystore` — тестовый ключ подписи (пароль `shooter3d`).
  Для Google Play нужно будет сделать отдельный секретный ключ.
